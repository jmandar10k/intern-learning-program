This page lists a few **extra** resources for after the program or for spare time. They are
not required and are outside the per-topic cap. All were verified on 2026-11-18
([log](link-verification-log.md)).

| Resource | Level | Why |
|---|---|---|
| [Andrej Karpathy: Neural Networks: Zero to Hero](https://karpathy.ai/zero-to-hero.html) | Advanced | Build neural networks and a small GPT from scratch; the best way to really understand LLM internals. Long (10+ hours); spread it over weeks. |
| [3Blue1Brown: Attention in transformers, step-by-step (Deep Learning Ch. 6)](https://www.3blue1brown.com/lessons/attention) | Intermediate–advanced | Visual intuition for attention; pairs well with the Illustrated Transformer. |
| [mypy: Type hints cheat sheet](https://mypy.readthedocs.io/en/stable/cheat_sheet_py3.html) | Intermediate | Quick reference for typing; keep it open while writing typed code. |
| [LangChain docs: RAG with Deep Agents tutorial](https://docs.langchain.com/oss/python/langchain/rag) | Advanced | An agentic RAG example built on the current LangChain stack, beyond this program's scope. |
| [OWASP: LLM Top 10 (2025) list](https://genai.owasp.org/llm-top-10/) | Advanced | One-page index of the ten LLM application risks; useful as a design-review checklist. |
