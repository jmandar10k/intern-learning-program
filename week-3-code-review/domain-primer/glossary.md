# Finance glossary (plain language)

| Term | Meaning |
|---|---|
| **Adjusted price** | Historical price rescaled for splits and dividends so returns are continuous |
| **Ask / bid** | Lowest price a seller accepts / highest price a buyer pays |
| **Asset class** | Group of similar investments: stocks, bonds, commodities, currencies… |
| **Backtest** | Simulation of a strategy's rules on historical data |
| **Bar** | One time interval of price data (OHLCV) |
| **Benchmark** | What a strategy is compared to, often an index |
| **Bollinger Bands** | Moving average ± 2 standard deviations |
| **CAGR** | Compound annual growth rate: constant yearly rate giving the same total growth |
| **Calmar ratio** | CAGR divided by maximum drawdown |
| **Commission** | Broker fee per trade |
| **Data snooping** | Testing many ideas on the same data and keeping the best |
| **Dividend** | Cash paid by a company to shareholders |
| **Drawdown** | Fall of equity from its previous peak |
| **Equity curve** | Account value over time |
| **ETF** | Exchange-traded fund; a fund that trades like a stock |
| **Ex-dividend date** | First day a buyer no longer receives the upcoming dividend; price usually drops by about the dividend |
| **Expectancy** | Average profit per trade |
| **Fat tails** | Extreme moves happen more often than a normal distribution predicts |
| **Futures** | Contract to trade an asset at a set price on a future date |
| **In-sample / out-of-sample** | Data used to design a strategy / later data held out to test it |
| **Index** | Number tracking a basket of assets |
| **Leverage** | Exposure larger than capital, through borrowing or derivatives |
| **Liquidity** | How easily an asset trades without moving its price |
| **Log return** | ln(P_t / P_{t−1}); adds over time |
| **Long / short** | Profit if price rises / falls |
| **Look-ahead bias** | Using information not yet available at decision time |
| **MACD** | Difference of 12- and 26-period EMAs, with a 9-period signal line |
| **Max drawdown (MDD)** | Largest peak-to-trough fall |
| **Mean reversion** | Tendency of prices to return toward an average |
| **Momentum** | Tendency of recent winners to keep rising for a while |
| **Moving average (SMA/EMA)** | Average of recent prices, simple or exponentially weighted |
| **OHLCV** | Open, high, low, close, volume |
| **Options** | Right, not obligation, to buy (call) or sell (put) at a set price |
| **Position sizing** | Deciding how much to buy or sell |
| **Profit factor** | Gross profit / gross loss |
| **Risk-free rate** | Return on a (near) riskless asset, e.g. short-term government bills |
| **RSI** | Relative Strength Index, 0–100 momentum oscillator |
| **Sharpe ratio** | Excess return / volatility |
| **Short selling** | Borrowing and selling an asset to buy back later, cheaper |
| **Slippage** | Difference between expected and actual fill price |
| **Sortino ratio** | Excess return / downside deviation |
| **Split** | One share becomes several; price divides accordingly |
| **Spread** | Ask − bid |
| **Stop loss / take profit** | Exit rules for a maximum loss / a profit target |
| **Survivorship bias** | Only analysing assets that still exist |
| **Timeframe** | Bar interval: minute, hour, day… |
| **Total return** | Price change plus dividends |
| **VaR** | Value at Risk: loss not exceeded with a given confidence over a period |
| **Volatility** | Standard deviation of returns |
| **Walk-forward** | Rolling tune-then-test evaluation over time |
| **Win rate** | Share of trades that made money |
