# Reference problem: FreshCart late deliveries

A neutral, fictional problem used for the study examples and exercises in Week 1. It gives the
concepts a concrete home; there is no real product behind it.

> **Assumption (per spec):** a neutral domain was used, not finance. Finance appears only in the
> Week 3 domain primer. Ask your mentor if a finance version is preferred.

## Context

**FreshCart** is a fictional grocery delivery service operating in four city zones. Customers
order online and choose a 1-hour delivery slot. A courier picks up the order from one of
several stores and delivers it.

Roughly one order in four arrives **late** (after the slot ends). Late deliveries drive
refunds and cancellations. Operations wants to understand why and predict which orders are at
risk, so they can add a courier or warn the customer in advance.

## Data (synthetic, generated by the exercises)

One row per order:

| Column | Type | Meaning |
|---|---|---|
| `order_id` | int | Unique order id |
| `zone` | category | City zone: `north`, `south`, `east`, `west` |
| `store_id` | int | Store the order was picked from |
| `hour` | int | Hour of the delivery slot (8–21) |
| `weekday` | int | 0 = Monday … 6 = Sunday |
| `items` | int | Number of items in the order |
| `basket_value` | float | Order value in currency units |
| `distance_km` | float | Store-to-customer distance |
| `courier_load` | int | Orders the courier already had in the same hour |
| `rain` | bool | Raining at dispatch time |
| `delivery_minutes` | float | Actual minutes from dispatch to door |
| `late` | 0/1 | 1 if delivered after the slot ended (**target**) |

Some columns have missing values and outliers on purpose.

## Questions used across Week 1

| Topic | Question |
|---|---|
| 01 Python | Model an `Order` and a `DeliveryBatch`; stream orders lazily; time and cache expensive functions; type and test the code. |
| 02 Data analysis | Which zones and hours have the highest late rate? Do per-zone totals reconcile with the raw data after cleaning and joining store metadata? |
| 03 Statistics | Is the late rate higher in rain? Is the difference significant? How correlated are distance and delivery time? What biases might the sample have? |
| 04 ML | Predict `late` (classification) and `delivery_minutes` (regression). Which metric matters to operations? Cluster orders into delivery profiles. Where could leakage creep in? |

## A trap to keep in mind

`delivery_minutes` is only known **after** the delivery. Using it as a feature to predict
`late` gives a near-perfect model that is useless in practice. That is target leakage, and
you will meet it again in Week 3 and in the finance primer as look-ahead bias.
